# Transkrip 2026-10-15_23-49

[23:49:02] Mereka: Customers report duplicate payments when they click pay invoice multiple times. How would you debug this?
           ↳ Saran (Sonnet 5.5): My first step is to reproduce it. I look in the logs for two payment requests for the same invoice, a few milliseconds apart, and in the payments table for two rows.  That tells me it's a race. The button click isn't the only cause, so I'd disable the button, but that's just user experience.  The real fix is a unique request key per payment attempt, a database constraint on it, and a lock on the invoice row. If it's already paid, I return the first receipt.
